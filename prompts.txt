1. LLM never computes priority scores.

3. LLM never invents CVSS/EPSS/KEV values.
4. LLM never executes tools.
5. LLM output is validated before display.
6. If AI fails, the deterministic template fills the panel.

| Failure | Recovery |
|---|---|
| Real backend down | Toggle `NEXT_PUBLIC_USE_MOCK=true`, restart frontend |
| AI provider down | Set `USE_MOCK_AI=true`; mock provider fills panel |
| AI returns invalid JSON | Validator retries once; falls back to mock |
| AI hallucinates | Validator catches; falls back to mock; logs warning |
| Injection payload succeeds | (Should not happen) Disable AI panel; show deterministic template |
| Case not found | 404 page with "Return to dashboard" |
| Slow dashboard | Use mock provider; skip real fetch |
| Slow AI | Set `USE_MOCK_AI=true` |
| Audit fetch fails | Show "Audit unavailable"; approval still works |
| Approval mutation fails | Show error toast; do not change UI state |
| Frontend crash | Restart `npm run dev`; use production build if time permits |
| Docker/backend unavailable | Mock provider is the fallback; demo continues |
